CYCLOPS

Camera-only, Yaw-aware Collision avoidance with Learned Obstacle Perception for Small UAVs

A quadrotor with one forward-facing camera, and no LiDAR or stereo, spots obstacles with a neural network. It estimates how far away they are with a second network and flies around them in real time.

How it works

Based on Zhang, Zhang & Cao, ICUAS 2020: plan the avoidance around what a single camera can actually measure.

  1. See. A small CenterNet-style CNN finds obstacles in each camera frame. A U-Net predicts a depth map from the same single image.
  2. Locate. Direction comes from the pixel position; distance comes from the depth network. When the depth is unreliable, the tracker switches to direction-only updates (the paper's Mode 2).
  3. Remember. An extended Kalman filter tracks every obstacle in the world, including its velocity, so moving obstacles are predicted ahead.
  4. Decide. The planner tries candidate velocities inside the camera's field of view, scores them with a potential field along short predicted paths, and rejects any that would break the stopping distance.
  5. Fly. A PX4-style cascaded controller turns the chosen velocity into motor speeds for a full 6-DOF quadrotor model.

Run it yourself

Python 3.10+ on macOS, Linux or Windows. Trained network weights are included in the repository.

git clone https://github.com/ac265640/CYCLOPS.git
cd CYCLOPS
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python scripts/live_demo.py

The dashboard has clickable controls for scenario, perception mode, pause, restart, new map, manual flight, return home, landing and speed. Click Help for an explanation of every panel.

The ROS 2 nodes for PX4 SITL + Gazebo are in ros2_ws/. They reuse the same perception, tracker and planner code but have not yet been run against a live PX4 simulation.
